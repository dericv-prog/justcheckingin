# #justcheckingin

A tiny, privacy-friendly conversation-starter generator. No backend, analytics, cookies, AI services, or external dependencies. Works offline once loaded.

## Publish on GitHub Pages
1. Create a public GitHub repository, for example `justcheckingin`.
2. Upload `index.html`, `README.md`, `LICENSE`, and `CONTENT-LICENSE.md` to the repository root.
3. In repository **Settings → Pages**, choose **Deploy from a branch**, `main`, `/ (root)`.
4. Your site will appear at `https://YOUR_USERNAME.github.io/justcheckingin/`.
5. Change the footer's placeholder `https://github.com/` link in `index.html` to your actual repository URL.

## Editing
All styles, wording, and JavaScript are in `index.html`. The `build()` function holds the original conversation starters. No build step required.
